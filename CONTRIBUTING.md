# Contributing to Nyakitsu

Thanks for helping build Nyakitsu.

1. Fork the repository and create a focused branch.
2. Run `npm install`.
3. Run `npm run check` and `npm run build` before submitting changes.
4. Keep AI provider code isolated from web-page code.
5. Never place API keys, tokens, cookies or personal browsing data in commits, fixtures or screenshots.
6. Security-sensitive browser-agent changes should document their permission and confirmation model.

Small, reviewable pull requests are preferred.
